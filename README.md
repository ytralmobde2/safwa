# صَفْوة

أداة ويب لقصّ تسجيلات الصلاة وإبقاء التلاوة فقط، وكل المعالجة داخل المتصفح.

## المزايا
- حذف التكبيرات والركوع والسجود والسكوت تلقائياً، واكتشاف عدد التسليمات بنفسه
- خيارات قص: الفاتحة لكل ركعة، «آمين»، السور، تحسين الصوت، إخفاء الفاصل
- خيار مع الفاتحة أو بدونها، وحذف سجدة التلاوة ووصل القراءة
- مراجعة المقاطع على خط زمني والاستماع لكل مقطع
- وضع نهاري وليلي
- صدى بثلاث درجات
- مكتبة محلية، ودمج عدة تلاوات بفاصل من 0 إلى 3 ثوانٍ
- تنزيل الناتج بصيغة m4a

## النشر على Vercel
1. ارفع الملفات إلى مستودع على GitHub.
2. من vercel.com/new اختر المستودع ثم Deploy، بلا أي إعدادات بناء.

## الخصوصية
لا يُرفع أي ملف صوتي إلى خادم، والمكتبة محفوظة في متصفح الجهاز.
